# Проект: витрина-приложение Telegram Mini App

## Где хранить файлы
Все файлы проекта сохраняются только в этой папке (Документы/mini-up-teleka):
- docs/    — исследования, концепции, стратегия, ТЗ (этапы I–X мастер-промпта)
- design/  — макеты, дизайн-система
- app/     — код мини-приложения (появится после согласования архитектуры)
- admin/   — админ-панель
- .claude/skills/ — скиллы проекта (не трогать)
- skills-upload/  — ZIP-архивы скиллов для загрузки в claude.ai

## Правила работы
- Служебные/временные/мусорные файлы (не нужные пользователю) сразу переносить в _to_delete/ — пользователь чистит её сам. Ничего не удалять.
- Секреты (токен бота и т.п.) — только в файле .env в этой папке, не в чате и не в коде.
- Не соглашаться автоматически; отделять факты от гипотез; не выдумывать цифры.
- Простой MVP. Никакого кода, пока не согласованы концепция и архитектура.
- Не больше 3 вопросов за раз; техническое объяснять просто.
- У админ-панели — отдельная серверная авторизация.
- Отвечать по-русски, кратко.

## Этапы мастер-промпта
I рынок и ниши → II три концепции → III стратегия и MVP → IV UI и дизайн-система →
V демо-шаблоны и модули → VI админ-панель → VII архитектура →
VIII коммерческая модель и форма заявки → IX план реализации → X тест спроса и метрики

## Текущий этап
Демо-витрина без сервера: prototype/index.html (логика) + prototype/data.js (все тексты и цены) → Yandex Object Storage (бакет bustool-showcase, публикация: `bash publish.sh`) → кнопка меню бота @Bustool_bot. GitHub — хранилище кода (Pages — запасной адрес).
Админка (с 19.10.2026): экран в витрине, виден только владельцу; проверка подписи Telegram и OWNER_TELEGRAM_ID — на сервере (Cloud Function admin/function, деплой `bash admin/deploy-function.sh`). Живые данные — data.json в бакете; prototype/data.js — исходник (залить: `bash publish.sh --data`). Данные не смешивать с логикой.
Заявки/контакты не собираем; кнопка «Обсудить проект» открывает чат с владельцем (CONTACT в коде).
Сервер, БД, 152-ФЗ, релей — только когда появится реальный клиентский проект.
